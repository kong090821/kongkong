🎨 UI/UX & 개인화 온보딩

  • 비회원 로컬 안심 이용 모드: 로그인 없이 비회원으로 시작하기 단일 버튼으로 즉시 체험하며, 데이터는 단말기 localStorage에 안전 보관.
  • 개인화 온보딩 설문:
    • 별명(닉네임) 입력: 메인 화면 상단에 "반가워요, [별명]님!" 개인 맞춤 인사말 적용.
    • D-Day 계산기: 출산예정일 입력 시 실시간 D-Day 및 주차/개월 수 연산.
    • 단일행 프로필 태그 바: D-Day, 성별, 분만법, 조리원, 지역 5가지 태그를 한 줄(Single Line)로 깔끔하게 배치.
  • 하단 네비게이션 & Safe Area: 스마트폰 하단 시스템 바에 [내 가방 확인하기] 버튼이 가려지지 않도록 보정 여백 적용.
  • 브랜드 앱 아이콘: 파스텔 웜톤 핑크 복숭아 출산가방 아이콘 적용 완료.

🌐 구글 시트 API 실시간 동기화 (`google_apps_script.js`)

  • 앱 재설치 없이 구글 시트 마스터 데이터(가방/용품/할일/혜택)를 실시간 반영.
  • 신규 바이럴 데이터 파란색 셀(#BBDEFB) 자동 시각화 및 미승인 항목 동기화 제외.
  • 선배맘 추천 TOP 3 및 맘카페 1위 최저가 구매 링크 탑시트 모달 제공.

📱 안드로이드 네이티브 백버튼 연동 (`MainActivity.java`)

  • 안드로이드 system back 제스처 및 하단 뒤로가기 버튼 클릭 시 앱 종료 대신 팝업/이전 화면 이동(window.handleHardwareBackPress).

📱 안드로이드 13~15 제스처/네비게이션바 뒤로가기 완벽 제어 & 화면 전환 안전 가드
  • [Android 13+ Native] OnBackInvokedCallback & dispatchKeyEvent 적용: 최신 안드로이드(Android 13, 14, 15)에서 시스템 뒤로가기 제스처나 네비게이션바 클릭 시 OS가 앱을 강제 종료하던 문제를 OnBackInvokedCallback 및 dispatchKeyEvent를 통해 완벽히 가로채어 임의 종료 차단.
  • [Navigation Guard] 서브 화면 백버튼 절대 종료 방지: 출산가방, 육아용품, 할일, 혜택, 내 가방 등 서브 화면을 이용 중일 때는 백스택 유실 여부와 상관없이 뒤로가기 클릭 시 절대 앱이 종료되지 않고 무조건 이전 화면 또는 홈 화면(dashboardScreen)으로 안전하게 이동하도록 currentActiveScreenId 안전 가드 강화.
  • [Exit Dialog] 메인 화면 [네/아니오] 팝업: 최상위 메인 화면(dashboardScreen)에서 뒤로가기 클릭 시에만 "꽁꽁 출산가방 앱을 종료하시겠습니까?" 팝업을 띄우고, [네] 선택 시에만 앱 종료, [아니오] 선택 시 팝업 닫기로 직관적 선택지 제공.
